# Проверка текста объявлений через GigaChat

Отдельный модуль. К публикации объявлений пока не подключён.
Проверяет только текст, фотографии не анализирует.

## Результаты

- approved — текст разрешён.
- rejected — текст отклонён.
- pending — требуется дополнительная проверка.

При ошибке подключения или некорректном ответе модели возвращается
pending. Пустой текст и текст длиннее 2000 символов вызывают ValueError.

## Установка

Команды выполняются из корня репозитория:

python3 -m venv backend/moderation/.venv
backend/moderation/.venv/bin/python -m pip install -r backend/moderation/requirements.txt

Скопируйте backend/moderation/.env.example в backend/moderation/.env.
Вставьте свой Authorization Key в GIGACHAT_CREDENTIALS.
Настоящий ключ в Git не добавлять.

## Проверка примеров

backend/moderation/.venv/bin/python backend/moderation/check_examples.py

Команда выполняет шесть запросов к GigaChat и расходует токены.
При первоначальном ручном запуске все шесть примеров дали
ожидаемый статус. Это не оценка точности на любых объявлениях.

## Подключение к бэкенду

Функция: moderate_text(text).

Возвращает словарь с полями status и reason.
Функция синхронная: при подключении к асинхронному FastAPI
её следует вызывать через asyncio.to_thread или фоновый механизм.

Публиковать объявление можно только при approved.
При rejected показывать причину и разрешать исправление.
При pending оставлять объявление неопубликованным до проверки.

Статус модерации хранить отдельно от статуса поиска животного.
Контакты и точный адрес передавать модели не требуется.
