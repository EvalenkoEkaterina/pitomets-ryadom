# Проверки этапа с координатами — 25 ноября 2026

Локально: PostgreSQL 17 (отдельный Docker-контейнер), Python 3.14,
React из актуальной `feature/react-start`, Google Chrome **158.0.0.0**.
Точка для проверки — тестовые 55.75, 37.62, не местоположение человека.
Постоянная тестовая пара VAPID хранится вне репозитория, сохранялась при рестарте.

## Настоящая база и настоящий браузер

1. В существующей странице `/#/notifications` выбрана тестовая точка.
   Кнопка включения создала настоящую PushSubscription без регистрации.
   В PostgreSQL сохранены обе координаты; интерфейс показал
   «Уведомления включены. Выбранная точка сохранена».
2. Ручная отправка объявления 99001 рядом с точкой:
   `selected:1, sent:1, skipped:0, failed:0`.
   Повтор: `selected:1, sent:0, skipped:1, failed:0`.
3. Процесс FastAPI остановлен и запущен с тем же PEM-ключом. Объявление 99002
   отправлено (`sent:1`). `getNotifications()` в Chrome подтвердил уведомление
   «После перезапуска» со ссылкой `http://localhost:5173/#/pets/99002`.
4. Вкладка React закрыта. Отправлено объявление 99004. После повторного открытия
   `getNotifications()` подтвердил новое уведомление «Закрытая вкладка» со ссылкой
   `http://localhost:5173/#/pets/99004`. До отправки такого уведомления не было.
5. Нажатие «Выключить уведомления» отключило настоящую подписку в PostgreSQL.
   Интерфейс показал «Уведомления выключены»; последующая отправка вернула
   `selected:0, sent:0, skipped:0, failed:0`.

Через настоящий HTTP API с той же браузерной подпиской дополнительно проверены:
отписка → повторное сохранение → изменение точки на 56, 38 (вне радиуса, selected:0)
→ возврат точки (sent:1) → повтор того же объявления (sent:0, skipped:1).
При дополнительной проверке повторное создание подписки кнопкой React после
отписки подтверждено: в PostgreSQL снова появилась одна активная подписка,
интерфейс показал успешное включение. Новое объявление 99006 отправлено
(`selected:1, sent:1, skipped:0, failed:0`). В Chrome через `getNotifications()`
подтверждено уведомление «Проверка перехода к объявлению» со ссылкой
`http://localhost:5173/#/pets/99006`.

Метод массовой отправки без заголовка токена при заданном серверном токене
возвращает HTTP 403. Случай незаданного токена (404) проверен автоматическим тестом.
Закрытый ключ, реальный endpoint и ключи подписки не включены в отчёт или коммиты.

## Автоматические проверки

11 Python-тестов, включая интеграционный тест настоящей PostgreSQL: прошли.
Проверены координаты, сохранность записи после пересоздания пула, обновление без
дубля, отключение, повторное сохранение, параллельное резервирование доставки,
одна отправка при двух вызовах, валидация API и защита ручных методов.

Радиус проверен на вычисленных данных: 999 м, 1000 м (включена граница), 1001 м,
нет точки, пересечение 180° долготы. Единицы расстояния — метры.

6 Node-тестов: прошли. Отказ в разрешении и ошибка сохранения проверены с
имитацией браузерных API; вызов permission — первый; отписка не теряется при
ошибке сервера. Обработчик `notificationclick` протестирован с имитацией события:
переход к `/#/pets/123` и фокус существующей вкладки.

TypeScript и production-сборка React: прошли. Lint изменённых файлов: прошёл.
Общий lint исходной ветки Лизы сообщает о пустом catch в `src/api/pets.ts`;
этот файл по просьбе Кати оставлен без изменений.

## Что ещё зависит от команды / ручной проверки

- Координаты и событие публикации/одобрения объявления в общем backend пока
  отсутствуют. Проверка рассылки использовала ручной защищённый вызов с тестовым id,
  а не публикацию через рабочий API. Автоматический вызов не подключён.
- Физический клик по системному баннеру пока не подтверждён.
  Переход проверен тестом обработчика, ссылка
  соответствует существующему HashRouter. Системные окна macOS недоступны инструменту.
- Нужно review бэкендера по DDL и постоянным production VAPID-ключам; review Лизы
  по root Service Worker и интеграции её страницы. Сообщения команде не отправлялись.

Это разделение результатов важно: принятие сообщения push-сервисом само по себе
не подтверждает его показ. Для пп. 3–4 отдельно проверен список уведомлений
браузера. Видеозапись и видимость системного баннера не зафиксированы.
