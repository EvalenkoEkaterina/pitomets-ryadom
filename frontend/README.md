# Питомец рядом — Frontend

Frontend-часть проекта «Питомец рядом» — сайта для поиска потерявшихся и найденных домашних животных.

## Технологии

- React
- TypeScript
- Vite
- CSS

## Запуск проекта

Перейдите в папку frontend:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Запустите локальный сервер разработки:

```bash
npm run dev
```

Откройте адрес, который появится в терминале (обычно `http://localhost:5173/`).

## Проверка и сборка

Проверка TypeScript и production-сборка:

```bash
npm run build
```

Проверка кода ESLint:

```bash
npm run lint
```

## Структура

```text
src/
├── assets/       # Изображения
├── components/   # Компоненты PetCard и PetList
├── pages/        # Страницы приложения
├── styles/       # Стили
├── App.tsx       # Корневой компонент
└── main.tsx      # Точка входа React
```

## Данные о питомцах

На текущем этапе используются тестовые данные, заданные в `src/pages/HomePage.tsx`.

Компонент `PetList` поддерживает состояния загрузки, ошибки и пустого списка.

## API

Подключение к backend API будет выполнено после согласования контракта с backend-разработчиком.

Ожидается получение списка питомцев через GET-запрос. Точный адрес API и формат ответа будут добавлены после согласования с backend-разработчиком.
