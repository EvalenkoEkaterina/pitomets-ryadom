# Питомец рядом — фронтенд

React, TypeScript, Vite. Все команды ниже выполняются в `frontend/`.
Нужен Node.js 22.12+ или поддерживаемая более новая версия и npm.
Python venv для фронтенда не требуется.

## Установка и запуск (Ubuntu / WSL)

```bash
cd /home/liza/pitomets-ryadom/frontend
npm ci
cp .env.example .env
npm run dev
```

Для другого пути к репозиторию перейдите в его папку `frontend`.
В PowerShell вместо `cp` можно использовать `Copy-Item .env.example .env`.
Откройте адрес, который напечатал Vite. Терминал оставьте запущенным.

## Настройка API

В `.env`:

```env
VITE_API_URL=https://fur-project-s56k.onrender.com
```

После изменения `.env` перезапустите Vite. Адрес API также задаётся при сборке.
Переменные с префиксом VITE_ видны браузеру: секреты в них не хранить.
`.env` исключён из Git, `.env.example` содержит только образец без секретов.

## Сборка и проверка

```bash
npm run build
npm run lint
npm run preview
```

Сборка записывается в `dist/`. `preview` позволяет проверить готовую сборку.
Для геолокации нужен HTTPS либо localhost и разрешение браузера.
Отказ в разрешении не мешает выбрать точку вручную.

## Реализовано

- Адаптивная главная: шапка, первый экран, три шага, уведомления, раскрывающиеся FAQ, описание проекта, подвал. Используются обычные HTML-элементы, не изображение страницы.
- Каталог: report_type=lost/found, species=cat/dog, фильтры в URL.
- Объявление: GET /api/pets/:id, загрузка, 404, ошибка и повторная попытка, возврат к фильтрам.
- Общая форма потери/находки: необязательная кличка, описание, место, телефон или Telegram, точка события.
- Отдельная точка для будущей подписки: /#/notifications.
- Карта OpenStreetMap: выбор кликом, стрелки перемещения, масштаб, ввод координат, запрос текущего места только по кнопке. Постоянного отслеживания нет.
- Предпросмотр JPEG/PNG/WebP до 5 МБ, замена и удаление. Фото ограничено шириной формы.
- Вход и регистрация с логином и паролем, проверкой пустых полей и совпадения паролей.

## Честные ограничения

- Публикация обновлённой формы временно заблокирована: существующий подтверждённый контракт использует contact_email, новый контракт телефона/Telegram и координат не предоставлен. Новые поля нельзя отправлять под предположительными именами — сервер может молча их проигнорировать. Кнопка проверяет данные и объясняет отсутствие отправки; данные остаются в форме.
- Старый createPet в api/pets.ts сохранён как адаптер прежнего API, но обновлённая форма его не вызывает. После согласования схемы нужно обновить NewPet, подключить POST и вернуть блокировку формы на время запроса. Успех показывать только после ответа сервера.
- Пользовательская авторизация не подключена. Административный /login не считается пользовательским API.
- Сохранение точки и включение/отключение push-подписки ожидают интеграции с Катей. Выбор точки не означает подписку.
- Фотография не отправляется на сервер.
- Предварительные ограничения интерфейса: кличка 100, место 100, описание 2000, контакт 100, логин 100, пароль 128 символов. Кличка необязательна; место, описание, контакт и точка обязательны в интерфейсе. Эти правила нужно подтвердить с бэкендером, они не объявляются согласованным контрактом.
- Проверка телефона: 10–15 цифр с необязательным + и разделителями. Telegram: @username или https://t.me/username, 5–32 символа, латинская буква в начале. Не проверяет существование номера или аккаунта.
- Карта требует доступа к tile.openstreetmap.org, атрибуция отображается под картой. При недоступности карты координаты можно вводить вручную.
- Контакт команды ещё не предоставлен: в подвале обычный текст, не вымышленные ссылки.
- FAQ описывает текущую готовность функций, обещания неподключённых возможностей отмечены явно.

## Что согласовать с командой

1. Бэкенд: названия полей телефона/Telegram и координат, обязательность, длины, формат POST и ответы ошибок; пользовательские вход/регистрация; загрузка фото.
2. Катя: контракт подписки, координаты и радиус, проверка состояния подписки и отписка.
3. Тимлид: контакт команды для двух ссылок в подвале.

## Проверка перед сдачей

- Ширины 320, 360, 390 и 1280+: все страницы, длинный текст, выбранное широкое фото, ошибки; горизонтальной прокрутки нет.
- Карта: выбор и смена точки, масштаб, отказ в геолокации, ручной выбор после отказа; точка объявления не меняет точку подписки.
- Каталог: обе комбинации фильтров, обновление, назад/вперёд, возврат из объявления.
- API: подтвердить фильтры на тестовых cat/dog с lost/found. Проверить 404 и сетевую ошибку без создания реальных объявлений.
- Формы: пробелы, плохой контакт, предел длины, несовпадающие пароли, ошибка без потери ввода. Неподключённые функции не показывают успех.
- Выполнить build и lint. Скриншоты и результат проверок: `docs/`.
