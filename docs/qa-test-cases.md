# Тест-кейсы: «Питомец рядом»

## Назначение

Документ содержит проверки требований к объявлениям о пропавших и найденных питомцах. Проверки подготовлены заранее и должны быть выполнены после того, как соответствующие функции появятся в приложении.

**Статус всех тест-кейсов на момент подготовки:** не выполнены. Фактический результат нужно заполнить после запуска приложения.

## TC-01. Просмотр объявления о найденном питомце

- **Цель:** проверить, что пользователь может открыть объявление и увидеть основную информацию.
- **Предусловия:** в приложении существует опубликованное объявление о найденном питомце.
- **Шаги:**
  1. Открыть список объявлений.
  2. Найти объявление о найденном питомце.
  3. Открыть его.
- **Ожидаемый результат:** открывается страница выбранного объявления; отображаются фотография (если она добавлена), описание питомца и место находки. Данные соответствуют выбранному объявлению.
- **Фактический результат:** не проверен.
- **Статус:** не выполнен.

## TC-02. Создание объявления с корректно заполненными данными

- **Цель:** проверить успешное создание объявления при заполнении обязательных полей.
- **Предусловия:** пользователь может открыть форму создания объявления.
- **Тестовые данные:** корректные значения всех обязательных полей; остальные поля заполняются при необходимости.
- **Шаги:**
  1. Открыть форму создания объявления.
  2. Заполнить все обязательные поля корректными данными.
  3. При необходимости добавить фотографию.
  4. Нажать кнопку отправки/публикации.
- **Ожидаемый результат:** приложение принимает данные и показывает подтверждение успешного создания либо открывает созданное объявление. Введённые данные сохранены и отображаются корректно.
- **Фактический результат:** не проверен.
- **Статус:** не выполнен.

## TC-03. Попытка создать объявление без обязательных полей

- **Цель:** проверить валидацию обязательных полей.
- **Предусловия:** доступна форма создания объявления; обязательные поля определены требованиями проекта.
- **Шаги:**
  1. Открыть форму создания объявления.
  2. Оставить обязательные поля пустыми.
  3. Нажать кнопку отправки/публикации.
- **Ожидаемый результат:** объявление не создаётся; пользователь видит понятное сообщение о необходимости заполнить обязательные поля или соответствующие поля выделяются. Введённые необязательные данные не должны бесследно теряться без объяснения.
- **Фактический результат:** не проверен.
- **Статус:** не выполнен.
- **Примечание:** точный перечень обязательных полей необходимо сверить с требованиями команды и реализацией формы.

## TC-04. Загрузка допустимой фотографии

- **Цель:** проверить добавление фотографии к объявлению.
- **Предусловия:** форма объявления поддерживает загрузку фотографий.
- **Тестовые данные:** изображение в формате, разрешённом требованиями приложения.
- **Шаги:**
  1. Открыть форму создания объявления.
  2. Выбрать допустимый файл изображения.
  3. Завершить создание объявления.
  4. Открыть созданное объявление.
- **Ожидаемый результат:** изображение загружается без ошибки, сохраняется вместе с объявлением и отображается в нём корректно.
- **Фактический результат:** не проверен.
- **Статус:** не выполнен.
- **Примечание:** допустимые форматы и максимальный размер файла нужно уточнить в требованиях проекта.

## TC-05. Попытка загрузить файл, который не является изображением

- **Цель:** проверить обработку недопустимого файла при загрузке фотографии.
- **Предусловия:** форма объявления поддерживает загрузку фотографий; правила допустимых файлов определены.
- **Тестовые данные:** файл неподдерживаемого типа, например текстовый файл, переименованный в `.jpg` либо обычный текстовый файл.
- **Шаги:**
  1. Открыть форму создания объявления.
  2. Попытаться выбрать или отправить файл, который не является допустимым изображением.
  3. Посмотреть на реакцию формы.
- **Ожидаемый результат:** приложение отклоняет файл, показывает понятное сообщение и не сохраняет его как фотографию объявления. Страница не должна аварийно завершать работу.
- **Фактический результат:** не проверен.
- **Статус:** не выполнен.
- **Примечание:** проверку необходимо выполнять в рамках разрешённых типов файлов, определённых требованиями проекта.
