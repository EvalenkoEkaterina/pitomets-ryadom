# Структура проекта «Питомец рядом»

Архитектура: React + TypeScript + Vite, FastAPI,
PostgreSQL + PostGIS, Web Push и проверка текста ИИ.

## frontend — фронтендер

Здесь находится React-приложение.

- src/components — карточки, кнопки и другие компоненты.
- src/pages — страницы приложения.
- src/assets — изображения.
- src/styles — CSS.
- package.json и конфигурация Vite — внутри frontend.

Готовый HTML переносится в React-компоненты.
CSS и картинки используются повторно.

## backend — бэкендер

Здесь находится FastAPI-приложение.

- app — основной Python-код.
- app/routers — обработчики запросов API.
- app/models — описание данных.
- app/services — логика приложения.
- tests — автоматические тесты бэкенда.
- requirements.txt — зависимости бэкенда.
- .env.example — пример настроек без секретов.

Внутреннюю структуру бэкендер адаптирует к существующему
коду и описывает в README.

## experiments — участница по уведомлениям

Отдельный пример размещается в experiments/web-push.

Внутри должны быть код и инструкция запуска.
После проверки серверная часть переносится в backend,
а браузерная — во frontend.

## docs — документация и тестировщица

Здесь хранятся:
- архитектура и описание решений;
- тестовые сценарии;
- отчёты о проверках и ошибках;
- инструкции для команды.

## Переход с Django

Старые config, manage.py, templates и static сохраняются
до переноса и проверки соответствующих частей.

Удаление Django выполняется отдельным изменением
после успешного запуска новой основы.

## Правила работы

Каждый работает в своей ветке и открывает PR в main.
В PR указываются изменения и способ проверки.

Файл .gitkeep можно удалить, когда в его папке
появятся настоящие файлы.

Пароли, закрытые ключи, реальные .env, node_modules
и локальные базы данных в репозиторий не загружаются.
